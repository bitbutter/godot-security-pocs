Note: the 'rpc node checksum failed' error below is expected and benign:

Demo shape: a malicious WebSocket server (server.py) pops a Godot 4.7
multiplayer CLIENT that connected to it. No file, no @tool, no autoload
beyond victim_client.gd. The server sends 3 binary WS frames: a 4-byte
peer id, a NETWORK_COMMAND_SIMPLIFY_PATH (caches the client's spawner),
then ONE crafted NETWORK_COMMAND_SPAWN whose sync_len overflows the
bounds check in on_spawn_receive.
